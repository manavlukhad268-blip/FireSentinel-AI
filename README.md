# FireSentinel AI 🛡️🔥
AI-powered voice threat & scam detection application designed for Amazon Fire TV / Vega OS (16:9 widescreen 10-foot UI).

## 🚀 Project Overview & Vision
FireSentinel AI protects users from voice scams, fraudulent calls, and security threats by analyzing incoming audio in real-time. It provides instant visual warnings on large smart TV screens and generates voice alerts to keep families safe from phishing and financial frauds.

## 🛠️ Tech Stack & Architecture
- **AI Brain & Core Logic:** Python, SpeechRecognition, Hugging Face open-source models.
- **Audio Output:** gTTS (Google Text-to-Speech) for instant threat warnings.
- **Backend & Storage:** Supabase database.
- **Target Platform:** Optimized for Amazon Fire TV / Vega OS 10-foot widescreen layout.

## ☁️ Note on AWS Integration & Future Scope
- **Current Status (Open-Source Track):** To ensure 100% free, card-free, and student-friendly development without billing or credit card dependencies during testing, the current live deployment runs on verified open-source Python libraries.
- **AWS Architecture Design:** The app's underlying architecture and SDK (`boto3`) structure are fully designed to integrate with AWS cloud services (such as Amazon Bedrock for AI processing and Amazon Transcribe for speech-to-text). 
- **Future Roadmap:** While deployed via the Open-Source track for this hackathon submission, we plan to transition and fully implement the real production-grade AWS cloud infrastructure in future updates as we scale the application.
